# 第一人称 2D 游戏

仓库已重置为新的 **2D 第一人称视角** 项目（走廊探索 + 手持物品 + 底部装备栏 UI，参考移动端地牢类玩法）。

## 项目目录

| 路径 | 说明 |
|------|------|
| `first-person-2d/` | 游戏工程（Vite + TypeScript + Phaser 3） |

## 快速开始

```bash
cd first-person-2d
npm install
npm run dev
```

浏览器打开终端提示的地址（默认 `http://localhost:5173`）。

## 技术栈

- **Phaser 3**：2D 渲染与场景
- **Vite**：开发与打包
- **TypeScript**

当前为**占位美术**（几何图形 + 文字），便于后续替换精灵与动画。

## 场景结构（`src/scenes/GameScene.ts`）

1. **走廊层**：透视地板与两侧墙  
2. **世界层**：远处宝箱、场景道具（示例：橡胶鸡）  
3. **前景层**：双手与左右手持槽  
4. **UI**：顶部货币/进度、技能条、底部生命与 4×2 装备格
